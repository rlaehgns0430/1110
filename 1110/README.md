
1. 비교 횟수와 실행시간

결과: 데이터가 커질수록 두 정렬 모두 완만하게 늘어남.
분석: 병합 정렬이 비교 횟수는 더 적지만, 실제 시간은 퀵 정렬이 대등하거나 더 빠름. 병합 정렬은 데이터를 임시 배열로 옮기고 되돌리는 복사 오버헤드 때문에 시간이 더 걸림.

2. 메모리 사용량

결과: 두 알고리즘의 차이가 가장 크게 나타남.
분석: 병합 정렬은 원본 크기만 한 임시 배열이 필수라 데이터 증가 시 메모리 소모가 심함. 반면 퀵 정렬은 추가 배열 없이 제자리에서 스왑하므로 재귀 스택 메모리 외에는 거의 쓰지 않음.

3. 퀵 정렬 피벗 선택 방식

결과: 세 원소의 중앙값 방식이 가장 우수함.
분석: 초기에 피벗을 고르는 연산이 추가되더라도, 배열을 가장 균등하게 분할하기 때문에 최종 비교 횟수와 스택 메모리를 가장 아낄 수 있었음.

4. 요약 및 기준

메모리 계산: 원본 배열을 제외하고, 병합 정렬의 임시 배열과 최대 재귀 스택 깊이만 기준으로 계산함.
결론: 대용량 무작위 데이터에서는 시간과 공간 효율성을 모두 챙길 수 있는 중앙값 피벗 퀵 정렬이 가장 최적의 선택임.
